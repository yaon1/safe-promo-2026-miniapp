## Сборка в NotiBot (порядок из ТЗ)
1. **BotFather** (делает Сергей): `/newbot` → имя «Безопасное продвижение 2026» → username `…_conf_bot` → токен.
2. **NotiBot** (делает Сергей): регистрация на notibot.ru → «Подключить бота» → вставить токен.
3. **Mini App**: в NotiBot «Мини-приложения» → создать → тип «Страница» (не «Визитка» — в ТЗ отдельно). В BotFather `/newapp` (или `/setmenubutton`) → URL мини-приложения из NotiBot, short name `conf`.
4. **Посадочная**: собрать блоками конструктора по `index.html` (тот же порядок и тексты; картинки — из `img/`): Картинка + Попап; Таймер (13 марта 15:00 МСК); Кнопка → Форма (имя, телефон, почта); после отправки формы — тег `registered`.
5. **Дожимы**: «Чат-боты» → «Автосообщение» → триггер «при открытии страницы» → условие: нет тега `registered` (сегмент «не заполнил форму») → задержка 5 мин — Дожим 1; задержка 10 мин — Дожим 2. Перед отправкой каждого — повторная проверка тега (если успел зарегистрироваться — не слать).
6. **UTM**: ссылка регистрации из дожимов — `https://t.me/<бот>/conf?startapp=dojim`; основная из канала — `?startapp=utmtg`. Метка видна в лиде (поле utm).
7. **Проверка** (как в ТЗ): открыть мини-апп с другого аккаунта, форму не заполнять → через 5 мин пришел Дожим 1, через 10 — Дожим 2. Затем заполнить форму на третьем аккаунте → дожимов нет.
8. Сдать: ссылку `https://t.me/<бот>/conf?startapp=utmtg` в чат «Тестовое тех спец».
